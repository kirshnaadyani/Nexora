1-Click Fix for Supabase Row Level Security (RLS)

If you added products in your Supabase table but they don't show up, Supabase's Row Level Security is blocking anonymous read requests. Copy the SQL script below and run it in your Supabase Dashboard > SQL Editor: 

-- Step 1: Ensure products table exists
CREATE TABLE IF NOT EXISTS products (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    category TEXT DEFAULT 'Ready-to-Wear',
    price NUMERIC DEFAULT 0,
    original_price NUMERIC,
    image TEXT,
    description TEXT,
    material TEXT,
    stock_quantity INT DEFAULT 10,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now())
);

-- Step 2: Grant public read/write access (Solves missing items issue immediately)
ALTER TABLE products DISABLE ROW LEVEL SECURITY;
